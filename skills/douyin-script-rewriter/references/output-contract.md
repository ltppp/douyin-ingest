# Downstream Output Contract

## Output Root

Create the run beside the ingest result file:

```text
<ingest-result-directory>/rewrites/<YYYYMMDD-HHMMSS>/
```

Do not write into the prerequisite transcript directory and do not alter ingest artifacts.

## Required Files

```text
<run>/
├── report.md
├── result.json
├── deliverables/
│   └── <account>-Top<N>内容改写-简洁版.docx
└── videos/
    └── <aweme_id>/
        ├── transcript_raw.txt
        ├── transcript_clean.txt
        ├── corrections.md
        ├── analysis.md
        └── rewrite.md
```

For a successfully processed video, `rewrite.md` is optional only when the user explicitly requested correction or analysis without rewriting; all other listed files are required. When at least one successful item contains `rewrite.md`, the consolidated Word file is required. For a failed downstream item, keep its entry in `result.json`, set unavailable artifact paths to `null`, and record a concrete error. Do not create placeholder artifact files that look successful.

The Word filename and location are generated by `scripts/build_word.py`; do not construct them manually. A profile uses `<account>-Top<N>内容改写-简洁版.docx`; a single video uses `<account-or-title>-单条内容改写-简洁版.docx`. Sanitize filesystem-reserved characters without changing the visible account/title inside the document.

## report.md

This is a user-facing result index, not a dump of processing evidence. Choose the template from `collection_mode`:

- `single_video`: [../templates/report-single.md](../templates/report-single.md)
- `profile`: [../templates/report-profile.md](../templates/report-profile.md)

Include only:

- Overall success or failure status.
- One consolidated Word link when rewritten scripts exist.
- Single video: original video, AI-corrected transcript, and rewritten script.
- Profile: account name, popularity-sorted Top X count, and one row per video with rank, likes, original video, AI-corrected transcript, and rewritten script.
- A short warning only when it materially affects use of the result.

Do not embed raw transcripts, corrected transcripts, correction logs, analysis, ingest paths, cache state, model details, validation output, or JSON in `report.md`. Those remain available as separate internal artifacts.

### Status Rules

- Every selected video completed: `已完成`.
- Some selected videos completed: `部分完成（M/N）`.
- No selected video completed: `未完成`.
- Keep failed profile items in their original rank. Use `处理失败` in unavailable result cells.
- `X` is the number of selected videos returned by ingest, unless the ingest result exposes the explicitly requested selection limit.
- For profile rewriting, the requested selection limit defaults to 5 when the user did not specify X.
- Profile ranking and likes come directly from `videos[]` and `digg_count`. Do not re-sort or recalculate popularity.

## result.json

Write UTF-8 JSON with this logical shape:

```json
{
  "schema_version": "1.1",
  "status": "partial",
  "source": {
    "collection_mode": "profile",
    "ingest_result_file": "/absolute/path/result.json",
    "cache_hit": false,
    "account_name": "账号名称",
    "selection_limit": 5
  },
  "videos": [
    {
      "aweme_id": "123",
      "title": "标题",
      "source_url": "https://www.douyin.com/video/123",
      "digg_count": 1000,
      "rank": 1,
      "status": "success",
      "quality_grade": "usable",
      "raw_transcript_file": "/absolute/path/transcript_raw.txt",
      "clean_transcript_file": "/absolute/path/transcript_clean.txt",
      "corrections_file": "/absolute/path/corrections.md",
      "analysis_file": "/absolute/path/analysis.md",
      "rewrite_file": "/absolute/path/rewrite.md",
      "warnings": [],
      "error": null
    }
  ],
  "report_file": "/absolute/path/report.md",
  "word_file": "/absolute/path/deliverables/账号-Top5内容改写-简洁版.docx",
  "word_template_version": "douyin-script-rewriter-word-v1"
}
```

Top-level `status` is `success`, `partial`, or `failed`. Per-video `status` is `success` or `failed`. Use `collection_mode` from ingest. A profile result remains popularity-sorted; a single-video result contains one item. `rank` is the 1-based position in the returned `videos[]` order.

`word_file` and `word_template_version` are required when the run contains rewritten scripts. They are absent for correction-only or analysis-only runs. Run the Word builder after all per-video artifacts and the initial `result.json` exist; the builder records these fields only after its structural verification succeeds.

## Fixed Word Content

The versioned builder creates one consolidated document with this exact order:

1. Cover: account/title, `Top N` or `单条`, content label, and run date.
2. Profile directory: rank, title, and likes in existing `videos[]` order. Omit for a single video.
3. One page-started section per item: `TOP NN`, title, likes, clickable original Douyin URL, optional transcription warning, `AI 校正版逐字稿`, and `原创口播稿` when available.
4. Failed items remain in rank order and show `处理失败` plus the recorded error.

Do not include raw ASR transcripts, correction logs, analysis notes, JSON, source filesystem paths, or implementation details.

## Validation

Before completion:

- Every non-null path recorded in `result.json` must exist and be non-empty.
- Every successful item must contain all artifacts required by the requested operation.
- Every failed item must contain a non-empty `error` and must not link unavailable artifacts.
- The raw transcript copy must match ingest `transcription.text` exactly, allowing only one final newline in the file.
- The clean transcript must not contain unsupported invented passages.
- Every `unreliable` item must include a warning and uncertainty markers. If the user explicitly requested a stronger-ASR retry, document it separately; never treat retry as the default remedy.
- The report source links must use durable `video_url` or legacy `page_url`, never temporary CDN media URLs.
- The report must remain a concise result index and must not duplicate the contents of artifact files.
- For rewritten runs, `scripts/build_word.py` must exit zero and print `"ok": true`.
- The Word validator must confirm the template version, non-empty OOXML package, exact item count/order, one `TOP NN` label per item, exact source-link set, required clean/rewrite section counts, full artifact text inclusion, no duplicate content headings, and no template placeholders.
- Per-run manual page inspection is not required for an unchanged certified template version. Re-render and visually inspect every page when layout code, template version, fonts, or renderer changes, or when structural validation fails.
